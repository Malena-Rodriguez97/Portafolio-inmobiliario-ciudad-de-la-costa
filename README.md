# Portafolio inmobiliario - Ciudad de la Costa

Análisis académico de 555 propiedades en venta y alquiler en 6 barrios de Ciudad 
de la Costa. 

Fuente: Mercado Libre Uruguay. 

Herramientas: BigQuery + SQL + Google Colab + Looker Studio.

Este proyecto se divide en dos secciones según el perfil de quien lo 
consulta: negocio/inversión y proceso técnico/metodológico.
